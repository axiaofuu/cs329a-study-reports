# Codebase Profile

## 输入

- 源代码
- README 与架构文档
- 包管理和构建配置
- 测试代码
- 数据库迁移、接口定义和部署配置
- 可选的运行日志与用户指定入口

敏感文件只识别名称，不读取内容。

## Pipeline

| 模块 | 输入 | 处理 | 输出 |
|---|---|---|---|
| Repository discovery | 仓库目录 | 识别语言、清单、入口、测试和配置 | `codebase-manifest.json` |
| Static evidence extraction | 源文件 | 提取导入、导出、函数签名和代码位置 | 文件级证据 |
| Module reconstruction | 文件级证据 | 按职责合并文件，建立内部依赖 | 模块图 |
| Flow tracing | 入口和依赖图 | 跟踪启动、请求、任务和错误路径 | 调用链与数据流 |
| Implementation explanation | 模块与调用链 | 解释作用、输入、输出、步骤和副作用 | 结构化正文 |
| HTML rendering | 正文、图和证据 | 应用报告模板和交互 | 独立 HTML |
| Quality gates | HTML 与证据图 | 检查引用、隐私、可读性和链接 | 已验证报告 |

## 最终输出

- 项目总览
- 模块地图
- 入口与核心执行路径
- 每个模块的作用、输入、输出和实现步骤
- 数据、状态、副作用和错误处理
- 构建、测试和部署说明
- 带文件和行号的证据定位
- 不包含答案的理解测试

## 质量门槛

- 核心模块不得缺少输入或输出。
- 架构图中的每条边必须有代码证据。
- 不能把文件名推断写成已确认事实。
- 报告不得包含敏感值或个人路径。
- 删除术语后仍能理解一次完整执行流程。
